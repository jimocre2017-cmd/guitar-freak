# Guitar Freak

毎日最低5分ギターに触り、1曲を最後まで確実に弾けるようにするための個人用レッスン兼記録アプリ。
筋トレアプリ（kintore）と同じ構成：**PWA（GitHub Pages）＋ GAS 同期API ＋ スプレッドシート「Guitar Freak」**。

- アプリ：[https://jimocre2017-cmd.github.io/guitar-freak/](https://jimocre2017-cmd.github.io/guitar-freak/)
- 要件定義書：[Guitar Freak 要件定義書](https://claude.ai/artifact/EfBuAaMxfkA14fFkQKLQhm)

## できること

| 画面 | 中身 |
|---|---|
| ホーム | 「今日まだ0分」/ 今日の分数と5分ライン、ストリーク、放置アラート（曲3日・基礎5日）、メイン曲の進捗ミニマップ、お知らせ |
| 練習 | 時間指定（5/10/15/30/60分・任意）か固定配分でメニューを自動編成 → 入れ替え・外す → タイマー＋メトロノームで1項目ずつ。終了時に音とバイブ、10秒で自動保存して次へ。スキップも記録 |
| 曲 | 曲・セクション登録（並べ替え可）、セクション×段階（ゆっくり/60/80/100%）の進捗マップ、通し・定着、譜面リンク、使うコード |
| 教材 | 運指・コード・スケール × G1〜G4（46課題）。指板図・コードダイアグラム・運指TABを同梱。目標BPMで✓を異なる3日 → 習得、80%習得で次のグレードを自動解放 |
| 分析 | 日/週/月/年（初期は週・月曜始まり）。練習カレンダー、項目別の時間と推移、曲ごとの進捗、習得一覧、BPMの推移、月ごとの達成日数、記録の修正・手入力 |
| 設定 | 同期、判定の日数・割合、時間指定の配分表、固定配分、テーマ、バックアップ（JSON） |

オフラインでもすべて動きます（記録は端末に保存し、つながった時に送信）。分析は端末内の記録から計算するので、オフラインでも最新です。

## スプレッドシートと同期APIの準備（1回だけ）

1. Googleスプレッドシートを新規作成し、名前を「Guitar Freak」にする
2. 拡張機能 → Apps Script を開き、`gas/Code.gs` の中身を `コード.gs` に貼り付けて保存
   （プロジェクトの設定 →「appsscript.json をエディタで表示」をオンにし、`gas/appsscript.json` も貼ると確実）
3. 関数 `setup` を選んで ▶実行 → 権限を許可。6つのシート（練習ログ・曲・セクション・課題・グレード・設定）と合言葉ができ、初期3曲が入る
4. デプロイ → 新しいデプロイ → 種類「ウェブアプリ」／実行するユーザー「自分」／アクセスできるユーザー「全員」
5. スプレッドシートを開き直し、メニュー **Guitar Freak → アプリ設定リンクを表示**
   - URLを聞かれたら、手順4の `/exec` で終わるURLを貼って保存し、もう一度開く
6. 表示されたリンクを、使う端末（スマホ・タブレット・PC）それぞれで1回開く → 同期の設定が保存される
7. Android では Chrome のメニュー →「ホーム画面に追加」でアプリとして使える

Code.gs を更新したら「デプロイを管理 → 編集 → 新バージョン」で同じURLのまま反映できます。

## シートの編集（Gemini）について

- 1行1レコード、IDで紐づけています。行の削除より「削除」列に `TRUE` を入れる方が安全です
- 同期は行ごとに「更新日時が新しい方が勝つ」ので、シートで直接直した行は **更新日時を大きい数字（例：今の値+1）にする** とアプリ側に反映されます
- 「段階ごとの到達日」「✓した日」「譜面リンク」は JSON 文字列です

